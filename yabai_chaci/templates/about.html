牙白查词 Yabai Search

牙白查词 / Yabai Search is a powerful Chinese–English dictionary. It supports many different search functions, along with Simplified characters, Traditional characters, Zhuyin/Bopomofo, and Taiwanese Mandarin.

Planned: Character search support, monolingual definitions, audio, example sentences, frequency, more sources (wikitionary).

Search tips

  • 漢字/汉字 - Search Simplified or Traditional Chinese
  • dangan - pinyin, any tone (matches 档案 单干)
  • *字 - Wildcard, search all words that end with 字
  • shi4shi2 - Specify tones
  • shi4shi - Leave tone blank, matches any tone
